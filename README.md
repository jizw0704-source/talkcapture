# 报告拾光 · TalkCapture

报告照片整理助手

[中文](README.md) · [English](README.en.md)

把手机拍摄的报告照片整理成图片版 PPT 或 PDF：导入照片，寻找投影画面，校正斜拍，核对页序，再生成文件。

面向科研报告、学术讲座和会议听众，帮助将散落在相册中的报告照片整理成便于回看、归档的演示文档。支持电脑导入、手机扫码传图、投影画面定位、透视校正和批量处理；保留原图与人工调整，遇到不确定的页面会集中提示检查。

当前版本为 **0.1.0 本地开发版**。已实现电脑导入、手机扫码传图、逐页校正和批量自动生成 PPT；真实多张照片的效果、真机整批流程和大量高清照片的稳定性仍待验收。尚未公开部署或接入 Pulse。

源码备份：[私有 GitHub 仓库](https://github.com/jizw0704-source/talkcapture)。访问需要仓库权限；本地照片和浏览器编辑数据不随源码同步。

## 当前功能

| 功能     | 当前行为                                                       |
| -------- | -------------------------------------------------------------- |
| 照片导入 | JPEG、PNG、HEIC / HEIF；最多 100 张，单张 30 MB，总计 1 GB     |
| 手机传图 | 同一可信 Wi-Fi 扫码，电脑批准后接收；每次最多一台手机、10 分钟 |
| 画面校正 | 本地几何定位、透视校正、手动四角、旋转、亮度和对比度           |
| 页面整理 | 调整页序，排除、恢复和批量移动；保留人工调整                   |
| 自动生成 | 主动点击“自动整理并生成 PPT”，问题页集中检查后继续             |
| 文件导出 | 图片版 PPTX / PDF，16:9 或 4:3，清晰优先或体积优先             |
| 项目恢复 | 本地缓存原图、页序与编辑参数；保存完成后刷新自动恢复           |

PPT 中每页是一张图片。目前不提供可编辑文字和图表、去重或遮挡信息恢复。

新增「分报告与内容总结」：macOS 本地识别文字并建议分组，可重命名、拆分、合并或移动页面；下载带页码和逐页原文的 Markdown 摘录总结。MiniMax 云端解读仅发送选中报告的识别文字，需本地配置 API 密钥；真实多场报告的分组与解读质量仍待验收。详见[使用说明](docs/usage.md)。

## 开始使用

需要 Node.js 24 和 pnpm，安装遵循现有锁文件。

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

打开 <http://127.0.0.1:9015/?auto-crop=1>。首次可点击“体验示例”，示例由程序生成。

1. 首选点击“手机传图”，扫码并在电脑批准连接后传入；也可点击“从电脑选择”。
2. 传完后点击“自动整理并生成 PPT”。保留当前页序和已有人工调整。
3. 如果出现“需要检查”，核对对应页面、确认或排除，然后继续生成。
4. 下载并检查文件。需要 PDF 或逐页操作时，使用“核对画面 → 导出报告”。

## 开发检查

```sh
pnpm format
pnpm format:check
pnpm typecheck
pnpm test
pnpm build
pnpm test:browser
pnpm start
```

修改代码时运行 `pnpm dev`；`pnpm preview` 与 `pnpm start` 相同。三个入口共用 9015 端口，不能同时启动。浏览器测试需要 Playwright Chromium；测试自动在 9025/9026 启动独立构建服务，不复用用户的传图会话。独立 ESLint 尚未配置。

## 数据与仓库范围

照片校正、预览和导出在本机浏览器中完成，原图不覆盖，编辑参数保存在浏览器本地数据库中。手机传图只在用户显式开启后使用本机局域网网关；当前 HTTP 传输不加密，只适合可信 Wi-Fi 下的非敏感材料。

本仓库维护源码、测试、锁文件、依赖补丁和项目文档。真实照片、生成的 PPT/PDF、浏览器数据、凭据、环境文件和测试生成物留在本地。仓库备份不包含照片或浏览器中的编辑项目。

右上角「设置」可配置 MiniMax 模型与密钥、测试已保存配置，选择浅色/深色/跟随系统和三档字号，并查看软件版本与构建时间。已有密钥不回显，页面保存到电脑端；显示偏好记住在当前浏览器。

界面支持中文与 English，在「设置 → 语言 / Language」即时切换并记住选择。手机扫码页面可继承语言或独立切换，原始文件名与识别原文保持不变。
