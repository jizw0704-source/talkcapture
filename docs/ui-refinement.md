# 2026-10-14 界面优化与结构简化

本轮优化现有电脑工具的操作界面，沿用 Pheno Design Language v1.4 和现有三步流程。主任务是传入照片并生成文件，辅助操作为核对、页序调整和导出设置；未改图像定位、透视校正、手机授权或原图保护逻辑。

两个新增 Skill 通过 Codex Skill Installer 安装在本机用户技能目录，保留来源记录。Impeccable 的上下文工具已运行成功；本轮没有安装项目编辑 hook。应用没有新增依赖、字体下载、云服务或图片上传服务。

## 第一次优化

- 导入页使用桌面双栏、窄屏单栏：使用说明与上传操作分区，电脑选择和手机传图采用并排的大按钮，示例为次要文字操作。
- 保留全部高级设置，默认继续收起。文件类型、容量和使用授权说明仍可见。
- 批量操作区显示保留页数、就绪页数或待检查页数；自动校正与人工确认的原有状态仍分别显示。
- 核对区增加桌面照片与预览高度，工具按钮分组，当前页面名称更清楚。缩略图有明确尺寸并延迟加载，预览图片的尺寸随内容更新。
- 文件生成后显示文件名、页数和体积，下载按钮靠近完成信息并成为主要操作；修改导出设置或照片后撤销旧下载结果。
- 增加可见于键盘焦点的“跳到主要内容”链接，保持至少 44 px 的入口、明确焦点、点击反馈和长文件名换行。

## 第二次：结构简化

用户反馈第一次变化不明显，要求更简洁、更好看。当前界面以本节为准，首次记录保留用于追踪。保持 Pheno 中性视觉语言，在现有结构内使用 Impeccable distill / layout 方法整理主次；独立只读布局评估与机械检查分开进行。

- 三步导航合并进顶栏，桌面单行、平板和窄屏两行。品牌和本机处理说明继续可见。
- 首页改为居中的单一上传区：两行标题、一句流程说明、一块上传面板。示例与项目设置降为面板下方的次要入口，空项目不再重复显示“尚未导入照片”。
- 上传图形是本项目绘制的 24×24 单色几何照片图标，1.5 px 圆端点描边；没有新增位图、外部图像或品牌 Logo。
- 批量操作改为紧凑摘要与按钮，去掉重复标题和外框。缺少原图的恢复状态在导入页显示重新选图提示，不展示无法使用的自动生成入口。已有文件时两条处理路径仍可达。
- 问题页列表采用桌面两列、窄屏一列和有限高度，保持全部问题可滚动查看与直接跳页；标题仍可接收键盘焦点。
- 核对区去掉页面栏和编辑区的外框，扩大可用空间；撤销和旋转采用文字操作，校正预览 / 原图对比采用紧凑分组，“校正并确认”突出为手动核对的主要操作。
- 导出设置保留，生成或下载阶段仍有明确的主要操作。未调整四角算法、参数、页序、原图或存储标识。

第二轮布局预检查没有报告布局问题。一般静态检测仍包含两个隐藏动态图片与外部 CSS 字号误报；另发现问题页标题存在 h1 到 h3 的跳级，已改为 h2 并保持原有视觉字号。桌面导入标题为 40 px、窄屏为 28 px。

## 检测与适用范围

Impeccable 静态检测报告了三项警告：两个动态图片没有初始 `src`，以及 HTML 默认字号层级不足。前两项对应初始隐藏的手机二维码与预览图：运行时获取有效图像后才显示；没有用占位图绕过。后一项因静态 HTML 检测未解析外部 CSS，把 body、h1、h2 均视为 16 px；实际 CSS 使用 14 px 正文、24 px 桌面品牌标题、40 px 导入标题，并在窄屏调整。以实际渲染核对为准，不能把这次检测说成零警告。

Vercel 检查采用适合本地工具的规则。没有套用 React 服务端渲染、第三方字体 CDN、公网 URL 状态、营销动画或品牌色替换。选图后刷新仍需要重新关联原图，保持原先的元数据恢复行为。

配色对比计算：次要文字 `#646464` 在 `#f7f7f7` 上为 5.52:1，在白色上为 5.92:1；白色文字在 `#101010` 按钮上为 19.03:1；焦点色 `#567700` 在白色上为 5.21:1。没有新增动画或透明表面。

MiSans 仍未随应用分发，使用系统字体回退；减少透明效果系统偏好未独立模拟，真机触控和真实照片整批验收仍待完成。独立 ESLint 尚未配置。
