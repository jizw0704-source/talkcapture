# 小范围新用户试用计划

状态：计划已准备，用户于2026-10-20选择先由自己按任务试用一轮；尚未招募或执行新用户试用。负责人由项目所有者指定，不自动联系任何人。本轮为形成性测试，用于找问题，不用于宣称总体成功率。

## 研究问题

1. 初次使用者能否从手机传图到完成分组导出，而不依赖开发者指导？
2. 用户能否区分画面确认、分组页序确认、疑似重复和倒序建议？
3. 用户能否正确保存与恢复项目，并理解恢复会替换当前项目？
4. 多组多格式导出、部分失败与重试是否容易理解？

## 人员与筛选

先邀请5名过去3个月内实际拍摄过会议、课堂或行业报告的用户。尽量覆盖3名iPhone与2名Android使用者，兼顾熟悉与不熟悉资料整理工具的人；不将项目开发者或看过操作演示的人计入首次使用样本。电脑端使用项目提供的受支持本机环境；不把macOS OCR可用推广为Windows已支持。

招募前询问：最近一次拍报告的场景、通常照片数量、手机与浏览器、后续如何使用资料、是否已经用过本工具、是否愿意用无敏感信息的授权样本测试。参与者可随时退出；默认只做匿名文字观察，截图、录音或屏幕录像需另行明确同意。是否提供酬谢由所有者事先决定，不作自动承诺。

## 测试材料与方式

默认主持式、每人约45分钟，同一可信局域网；先用15–20张合成或明确获授权的非敏感图片，混合3份报告、1对相似页、1张误选图、1组倒排以及1张需要微调的照片。观察者事先写下正确分界和预期页序。真人报告不得放入GitHub；不测试付费云端解读。工具自己的示例仅用于练习，不作为真实找角准确率证据。

每人使用独立测试项目/浏览器配置，先做好已有项目备份。不要在真实工作项目里模拟损坏原图或清理缓存。

场景只告诉参与者目标，不提示按钮名称或路径。发生困难时先等待并询问其预期，再给帮助；记录帮助次数，不将帮助后的完成算作独立成功。

每项记录：独立完成/帮助后完成/未完成、开始与结束时间、错误次数、帮助次数、用户误解原话。完成后问单题易用性评分（SEQ）：1=非常困难，7=非常容易。结束后可使用标准10题SUS问卷，奇数题减1、偶数题用5减回答，总和乘2.5；这是0–100的量表分数，不是成功百分比。

## 事先定义的推进条件

- 核心整理和导出至少4/5人独立完成，核心任务SEQ中位数至少5/7。
- 数据保护相关任务不得出现不可恢复误替换、误删或其他组被意外改动；任何一次都先修复再扩展试用。
- 来源页码、已确认选区、重复页保留规则等数据一致性检查必须全部通过。
- 时间预算用于定位卡点，不因为超时就诱导或代替参与者操作。
- 不满足条件时优先修复重复出现的问题，再邀请新用户复测；5人的结果不外推为市场总体指标。
