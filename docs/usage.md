# 产品范围与使用方法

本文整理当前本地开发版的实际功能。电脑编辑界面分为“导入照片 → 核对画面 → 导出报告”，批量自动整理由用户主动点击启动。输出为图片版 PPTX 或 PDF，尚不恢复可编辑文字和图表。

产品需求源于《学术报告拍照整理助手 PRD》V2.3。2026-10-04 增补手机传图和自动定位，2026-10-07 增补主动批量整理；这些范围已落实到当前代码。原始需求文件保留在项目所有者本地，仓库通过本文和工程约定记录当前实现。

## 逐页核对

界面分为“导入照片 → 核对画面 → 导出报告”三个步骤，顶部可以来回切换。导入成功后自动进入核对；切换步骤不会重新识别、覆盖四角或丢弃原图。导入设置、更多调整、页序与批量操作、更多导出选项默认收起，按需展开。恢复了参数但尚未重新关联原图时，默认停留在导入页。

1. 选择或拖入 JPEG、PNG、HEIC / HEIF 照片。项目最多 100 张，单张不超过 30 MB，总大小不超过 1 GB；损坏或不支持的文件单独列出。
2. 默认自动寻找完整 PPT 画面并生成校正预览，所有结果仍为待确认。检查是否保留完整内容；拖动四角、坐标输入和方向键均可微调。未找到可靠边界或多个候选难以区分时，照片保留，按左上、右上、右下、左下手动点选四角。放大后可拖动画布，辅助放大镜帮助定位。
3. 点击“校正并确认”。默认跳到下一张；每张自动定位的建议独立保留，不用上一张的四角覆盖。关闭自动定位后，尚未选点、没有识别失败标记且旋转方向相同的下一张可沿用上一张归一化四角；仍须检查并确认，不会自动确认所有照片。
4. 在核对页的页面列表中拖动排序；展开“页序与批量操作”可使用上移、下移，并勾选后批量排除、恢复或移动到指定位置。排除只是从输出中移除，不删除原图。
5. 点击“去导出”，选择 PPTX 或 PDF，以及 16:9 或 4:3 页面，点击生成后下载。未确认页会阻止导出，除非明确勾选按原图导出未确认页。

“导入时自动找出 PPT”可关闭，关闭后新增照片仍走手动流程。“自动找出 PPT”按钮可重新尝试当前页；识别成功会替换当前四角并要求重新确认，可用“撤销四角操作”恢复上一组选点。识别失败或点击“取消识别”不会覆盖现有选区或已确认状态。重新关联原图时不重新检测，也不覆盖保存的手动参数。

自动定位只是本地边缘与直线几何分析，并不理解报告内容。白板、窗户、图表等矩形也可能被误选；低对比边界、反光、遮挡、严重斜拍和四角出框可能找不到。必须核对预览，不能把工具的候选区域当作准确率保证。缺失或模糊的信息无法恢复。

## 手机扫码传图（本地体验版）

1. 手机和电脑连接同一可信 Wi-Fi。在电脑点“手机传图”，选择 Wi-Fi 地址，点击“生成二维码”。
2. 手机扫码，在浏览器中打开页面并点击“申请连接”；电脑确认是自己的手机后点击“允许这台手机”。
3. 手机选择照片并点击“传到电脑”。上传进度按实际传输字节显示。收到文件不等于导入成功：手机先显示“等待导入”，电脑完成读取后才显示“电脑已导入”；失败照片可重试。
4. 照片自动加入电脑当前项目，使用同一自动定位、人工确认、排序和导出流程。完成后点击“停止传图”或“关闭入口”。

每次连接最多 10 分钟、1 台手机、100 张/1 GB，单张最多 30 MB。电脑忙于校正或导出时，照片暂候；超过 8 张待导入会提示稍后重试。项目导入总上限仍按已有照片累计检查，并非每次扫码都重新获得 100 张容量。不要把二维码或带连接信息的链接发给别人。

此版本使用 **HTTP，传输不加密**，只能在可信局域网试用，不能用于公共 Wi-Fi、敏感报告或公开互联网。应用不自动改防火墙，不开启公网隧道，也不接入云存储。手机端不提供照片编辑、自动删除相册或释放空间；确认导出的文件完整并另有备份后，是否删除原图由用户自己决定。

网关将原始字节暂存在系统临时目录中，目录为 `report-photo-transfer-*`，照片用随机文件名和仅当前用户可读写权限保存。电脑确认导入或拒绝后删除该暂存文件；关闭、过期、电脑页面失联超过 90 秒及正常停止服务时清理本次目录。异常强制终止或断电可能留下临时文件，不能宣称绝对零落盘或所有崩溃后自动清理。电脑浏览器只持有内存中的照片，刷新后仍需重新导入。

如果手机打不开：检查选的是 Wi-Fi 地址、两端处于同一网络、未使用访客网络或禁止设备互访的校园网；检查系统是否阻止本地服务连接。可以尝试在系统浏览器中打开，必要时由用户手动允许本地网络访问。工具不会绕过访问限制；不具备局域网条件时，仍可先用系统文件传输再电脑导入。

编辑参数自动保存在当前浏览器的 IndexedDB（浏览器本地数据库），不保存原始图片内容。刷新后需重新选择照片；匹配文件名、大小、修改时间并恢复既有页序和参数。清空项目会移除本地编辑参数，不触碰电脑原图。切换浏览器、清理站点数据或更换服务地址后，本地参数可能无法访问。

## 自动整理并生成 PPT

2026-10-07 用户授权新增批量自动流程，见 PRD 第 24 节。先用电脑导入或手机传入整批照片，传完后在核对页点击“自动整理并生成 PPT”。沿用当前页序、已确认结果、已有手动四角、旋转、亮度和对比度；没有选区的页面才尝试自动定位，不根据内容重排、不自动去重、不统一缩小四角。主动批量整理时会尝试定位，即使导入时的自动定位开关关闭。

有明确四角且通过几何校验的页面自动校正，状态标为“自动校正 · 建议检查”，与“已确认”分开。每页仍是从原图生成的图片。全部保留页就绪后自动生成 PPTX 并提供下载入口；沿用导出设置里的页面比例、质量和报告名称，格式固定为 PPTX。初始设置为 16:9、清晰优先。工具不自动下载到磁盘，也不恢复可编辑文字、理解报告内容或补全遮挡。

多个候选、找不到边界、不完整或失效的手动四角、缺少原图、处理失败的页面集中列入“需要检查”列表。其余成功页面保留；整份文件暂停生成，不静默漏页，也不使用“按原图导出未确认页”来自动绕过。点击列表中的页面可手动核对并确认，或排除；完成后点击“继续整理并生成 PPT”。取消覆盖定位、校正和文件生成阶段，保留已完成页面和原有编辑；封装阶段不能立即停止第三方库，但会丢弃结果，可重试。

普通导入仍停留在待确认状态，不因照片到达而自动确认或自动导出。手机传图授权、容量限制、本地处理、只保存元数据和原图保护不变。几何候选不是经过校准的识别概率，批量生成不代表自动裁切一定正确，下载后仍建议检查完整内容。

## 图像质量和处理限制

透视变换采用双线性插值，亮度和对比度默认不调整。清晰优先输出最长边不超过 3200 像素，JPEG 质量 95%；体积优先为 1920 像素、82%。输出不会主动放大低分辨率原图，可能进行下采样和有损压缩，不能宣称输出与原图完全无损。原始文件始终保持不变。

自动定位使用最长边不超过 640 像素的分析图，只返回归一化四角，不修改或替代原文件。校正预览最长边为 1400 像素，原图对比预览为 1800 像素；最终导出重新从原文件生成，不使用低分辨率分析图或预览。页面等比例容纳图片，不拉伸或额外切边。四角能确定透视映射，但不能唯一确定真实屏幕的长宽比；输出选区比例按边长估算，严重斜拍可能仍需更准确的四角或后续比例设置。

大图在处理过程中先限制最长边到 5000 像素；超过 8000 万像素的照片拒绝处理。后台逐张处理，主动释放位图及失效预览。PPTX/PDF 库仍需保留各页编码数据来封装文件，因此接近 1 GB 的照片项目不等于已验证可在所有设备上导出。操作超时会重建处理程序。封装阶段无法立即中断第三方库，取消会丢弃最终结果。

HEIC 使用浏览器原生解码或本地解码器。已有一个 macOS 编码样例的验证，尚未覆盖各代 iPhone、多帧、HDR、不同色彩空间等情况。严重模糊、过曝、遮挡导致的缺失信息不能恢复。手机浏览器或相册可能在提供文件时转换格式；网关保留浏览器实际提供的字节，不保证其与相册中的源文件逐字节一致。
