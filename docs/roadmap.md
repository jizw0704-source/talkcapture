# 后续计划与验收

状态日期：2026-10-16。当前为 0.1.0 本地开发版，核心流程已实现，下一阶段重点是实际使用验收。

新一轮先按 [实测清单](acceptance.md) 走四步主流程，逐项记录，不以历史试用代替新版验收。

## 已实现的范围

- 电脑导入 JPEG、PNG、HEIC / HEIF，以及同一可信局域网手机扫码传图。
- 本地定位投影画面、透视校正、四角微调、旋转、亮度和对比度调整。
- 页序调整、批量移动、排除和恢复，原图保护与编辑元数据恢复。
- 用户主动触发批量自动校正，集中检查问题页，取消后继续。
- 本机 OCR 分报告、智能命名、人工拆并与页归属调整。
- 按组图片版 PPTX / PDF 与逐页原文 Markdown 导出，共用命名和检查入口。
- 照片墙、大图浏览、批量核对与疑似重复提示，不自动删除。
- 紧凑分组总览、可选 MiniMax 文字解读、中英文、主题与字号设置。

此前已进行单张真实照片的人工微调和 PPT 导出试用。该反馈不能替代新增批量自动流程的验收。

## 第一阶段：真实照片完整流程

优先使用一组 5–10 张有权处理的非敏感报告照片，覆盖正常拍摄、斜拍、暗光、反光、遮挡和难以定位的画面。

- [ ] 手机优先或电脑导入整组照片，完成核对 → 分报告与命名 → 按组导出。
- [ ] 逐页检查选中的是正确投影画面，标题、正文、图例和边缘内容没有被错误裁掉。
- [ ] 检查问题页能手动调整、确认或排除，并继续生成完整文件。
- [ ] 核对页序、人工参数和排除状态，确认没有漏页或用原图静默绕过失败。
- [ ] 在定位、校正和文件生成阶段取消，确认重试保留已有结果。
- [ ] 分别下载PPTX、PDF和原文Markdown，检查页数、范围、来源页号和可读性。
- [ ] 修改名称、折叠界面和刷新后核对已有分组、页序、选区与确认状态。
- [ ] 可选批量快速整理单独验收，不代替按组主流程。

验收记录应注明照片数量、场景、设备、发现的问题和处理结果。照片与含照片的导出文件留在本地；仓库仅记录必要的文字结论。

## 第二阶段：手机、容量与兼容

- [ ] 真机手机扫码 → 电脑批准 → 相册传图 → 整批校正 → PPT 下载完整跑通。
- [ ] 分别记录 iPhone Safari 与 Android 浏览器、相册格式转换和 Wi-Fi 情况。
- [ ] 验证传输中断、拒绝连接、过期和关闭入口后的行为。
- [ ] 逐步增加高清照片数量，最终检查 100 张高分辨率照片的内存、时间和导出稳定性。
- [ ] 在实际 Chrome、Edge、Safari 和 PowerPoint 中分别验收；不能用 Chromium 自测替代。
- [ ] 扩展到 5–10 名试用者、10 组真实报告照片，记录裁切问题和操作阻碍。

100 张小图的开发测试已经通过，不代表 100 张高清照片已验收。文件大小上限也不是设备性能保证。

## 后续候选，尚未定为开发任务

现已提供本机文字线索分组建议、人工调整与疑似重复页提示，均需核对；不自动排除或删除重复页。可编辑文字和图表恢复、Pulse 对接及公开部署仍未实现。后续根据真实使用验收再决定优先级和数据处理方案。

当前手机网关使用 HTTP，只用于可信 Wi-Fi 下的非敏感材料。若要扩展到公共网络或敏感报告，需先重新设计传输与访问保护。
