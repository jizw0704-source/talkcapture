## 中文项目介绍

报告拾光（TalkCapture）是一款面向科研报告、学术讲座和会议听众的本地工具。用户可以从电脑导入照片，或通过同一可信 Wi-Fi 下的手机扫码传图。工具尝试定位投影画面、校正斜拍，支持手动微调四角、调整页序，以及批量生成图片版 PPT；不确定的页面集中列出，核对后继续处理。原始照片保持不变，图像处理和文件生成在本机完成。

当前为可本地试用的开发版。支持 PPTX 和 PDF 导出，每页保留为图片；提供本机 OCR 分组建议、智能命名和疑似重复页提示，分界和重复页取舍由用户核对；原文 Markdown 保留逐页文字与来源页码。尚不恢复可编辑幻灯片或图表，不自动删除重复照片。真实照片批量效果、真机传图和大量高清照片的稳定性仍待验收。

## English one-line description

Correct, group and name presentation photos, then export image-based PowerPoint, PDF or source-linked Markdown.

## English project introduction

TalkCapture is a local tool for people attending academic talks, research presentations, and conferences. Import photos from a computer or transfer them from a phone over trusted Wi-Fi with QR pairing and desktop approval. The tool attempts to locate the projected slide, correct perspective, and organize pages into an image-based PowerPoint deck. Manual corner adjustments and page order are preserved, and uncertain pages are collected for review before generation continues. Original photos remain unchanged, and image processing and file generation run locally.

The project is currently a local development release available for trial use. It exports PPTX and PDF documents with an image on each page. Local OCR suggests report groups and titles; possible duplicates are flagged for human review. Source Markdown retains page text and source references. Editable slides and charts are not reconstructed, and duplicate photos are never deleted automatically. Real photo batches, physical phone workflows, and large high-resolution collections still require acceptance testing.
