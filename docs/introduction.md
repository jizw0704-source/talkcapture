# 中英文项目介绍与名称建议

[中文 README](../README.md) · [English README](../README.en.md)

以下介绍使用当前功能名称。候选品牌尚未确定，确定后再统一调整界面、文档与仓库说明。

## 中文一句话介绍

将学术报告照片整理成图片版 PPT 或 PDF，让拍下的内容更方便回看与归档。

## 中文项目介绍

学术报告照片整理助手是一款面向科研报告、学术讲座和会议听众的本地工具。用户可以从电脑导入照片，或通过同一可信 Wi-Fi 下的手机扫码传图。工具尝试定位投影画面、校正斜拍，支持手动微调四角、调整页序，以及批量生成图片版 PPT；不确定的页面集中列出，核对后继续处理。原始照片保持不变，图像处理和文件生成在本机完成。

当前为可本地试用的开发版。支持 PPTX 和 PDF 导出，每页保留为图片；尚不提供可编辑文字、图表恢复、内容自动分组或去重。真实照片批量效果、真机传图和大量高清照片的稳定性仍待验收。

## English one-line description

Organize photos of academic presentation slides into an image-based PowerPoint deck or PDF for later reference and archiving.

## English project introduction

Report Photo Organizer is a local tool for people attending academic talks, research presentations, and conferences. Import photos from a computer or transfer them from a phone over trusted Wi-Fi with QR pairing and desktop approval. The tool attempts to locate the projected slide, correct perspective, and organize pages into an image-based PowerPoint deck. Manual corner adjustments and page order are preserved, and uncertain pages are collected for review before generation continues. Original photos remain unchanged, and image processing and file generation run locally.

The project is currently a local development release available for trial use. It exports PPTX and PDF documents with an image on each page. Editable text and chart reconstruction, semantic grouping, and deduplication are not yet supported. Real photo batches, physical phone workflows, and large high-resolution collections still require acceptance testing.

建议标语：**把报告照片，整理成可回看的演示文档。**

Suggested tagline: **Gather slide photos into a deck you can revisit.**
