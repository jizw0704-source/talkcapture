## 仓库结构与边界

- `src/`：电脑界面、找角与校正、分组与导出、本地存储。
- `server/`：本机静态服务、手机授权传图、macOS OCR、可选 MiniMax 与模型设置。
- `shared/`：电脑与手机共用的中英文界面。
- `tests/`：单元与独立端口浏览器回归。
- `public/`：已采用的品牌、图标与字体等静态资源。
- `validation/`：找角对比入口；结果不替代真实照片验收。
- `patches/`、pnpm 锁文件：既有依赖和 PPTX 补丁，保持原样。
- `docs/`：功能说明、开发记录和验收步骤；`docs/showcase/` 仅收录已审查合成展示图。

内部包名与 IndexedDB 标识仍使用历史的 `report-photo-organizer`，不因仓库更名而迁移，避免影响已有项目。保留目录和模块位置，不在实测前进行大规模拆分。

现有浏览器照片项目不属于 Git 仓库；同步源码不能备份照片与选区。真实照片、导出文件、密钥和浏览器数据库均不提交。测试在9025/9026运行，不重启用户9015/9016服务。
