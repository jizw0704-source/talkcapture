# README 展示素材

这些截图于 2026-10-16 从独立的本地演示环境拍摄，使用工具内置的三张合成幻灯片，没有导入真实报告、个人照片或 API 密钥，没有开启手机配对，也没有调用云端分析。

- `review-zh.jpg` / `review-en.jpg`：原图选区与处理预览。内置示例主要展示裁切和核对界面，不是斜拍真实照片的准确率评测。
- `groups-zh.jpg` / `groups-en.jpg`：本机 OCR 后将第 3 页人工拆分为第二组，保留英文示例标题。截图展示分组操作，不宣称自动检测出了两份报告。
- `export-zh.jpg` / `export-en.jpg`：选择第一组，展示原文 Markdown 格式入口。PPTX 和 PDF 能力见使用说明；截图不代表已下载的文件。
- `import-zh.jpg`：电脑端的手机上传优先入口，无二维码或连接凭据。

中英文截图使用同一批资料。界面切换语言不会翻译原始文件名、报告名称或识别内容；英文截图保留这些用户内容。当前英文分组状态提示仍有一句中文，按实际界面保留，待主线程处理界面翻译时更新截图。

这里的 JPEG 是人工检查过的文档资产，由 `.gitignore` 的限定规则允许跟踪；其他照片、导出文件和测试截图继续排除。截图需随相关界面变化更新，不添加真实材料作为演示。
